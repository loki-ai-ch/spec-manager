# v0.4.5 - Design Context Parity

## Added

- Integrated DESIGN.md parity into native spec-manager design context workflows.
- Added design lint parity rules for missing primary colors, missing typography, missing sections, unknown keys, token-like ignored maps, unresolved prose token references, orphaned color tokens, token summaries, and contrast warnings.
- Added `tailwind-json` and `tailwind-css` export formats to `spec-manager assist design-export`.
- Added repository-local DESIGN.md conformance fixtures copied from the upstream design.md examples and linter fixtures.
- Added non-blocking Design Guidance in Agent Briefs for UI requests with DESIGN.md.
- Added `assist critique` advisory for UI/design specs that do not explain how agents should use DESIGN.md prose and constraints.

## Changed

- Expanded README, Chinese README, skill docs, and CodeBuddy skill template with Design Context parity guidance.
- DESIGN.md verification remains non-blocking for warnings and still fails on errors.

- `npm test`

- CLI smoke tests for design-template, all design-export formats, Agent Brief guidance, and critique advisory.
