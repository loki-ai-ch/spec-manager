# v0.4.10 - Workflow Guidance and Task Auto-Start

## Added

- Added `spec-manager task create <L3-code> --plan <planFile> --start` for frozen L3 specs. The command creates and immediately starts the Task while preserving the default draft-only `task create` behavior (`l3-task-start-shortcut-L1`).
- Added text and JSON output for the auto-start path, including `startedAt` and the next `task step` command (`l3-task-start-shortcut-L3.1.1`).

## Changed

- Unified README, skill, and agent template guidance around three explicit paths: confirm-only, draft L3 `task run`, and frozen L3 `task create --start` (`l3-task-start-shortcut-L3.1.2`).
- Strengthened L1/L2/L3 template boundaries and made plan examples language-neutral (`template-governance-hardening-L1`).
- Expanded docs consistency checks to cover every published agent guidance template and required workflow, design-context, acceptance, and delivery instructions (`template-governance-hardening-L3.1.2`).
