# DC-001 — 以 CLI 为工作流事实源，统一 agent 入口并强化规格、计划和任务状态校验。

> 关联 spec: **workflow-hardening-L1**  |  状态: **active**

## 决定
以 CLI 为工作流事实源，统一 agent 入口并强化规格、计划和任务状态校验。

## 为什么
防止不同工具入口产生流程漂移，并让错误在实施前被发现。
