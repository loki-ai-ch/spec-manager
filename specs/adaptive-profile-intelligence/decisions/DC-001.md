# DC-001 — Adopt local deterministic Profile recommendation and governance metrics for quick/standard/governed selection, with explainable risk factors, stable JSON output, and local aggregation over Task profile/evidence records.

> 关联 spec: **adaptive-profile-intelligence-L1**  |  状态: **active**

## 决定
Adopt local deterministic Profile recommendation and governance metrics for quick/standard/governed selection, with explainable risk factors, stable JSON output, and local aggregation over Task profile/evidence records.

## 为什么
This makes Profile selection consistent and auditable after adaptive workflow support, while preserving legacy compatibility: recommendations are advisory, overridable with recorded rationale, and must not auto-enable or tighten project workflow semantics.
