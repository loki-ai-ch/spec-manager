# DC-001 — 保留 task run 作为 draft L3 的确认并执行主入口；为 frozen L3 增加显式 task create --start；不传 --start 时 task create 继续只创建 draft，并保留分步 create/start。

> 关联 spec: **l3-task-start-shortcut-L1**  |  状态: **active**

## 决定
保留 task run 作为 draft L3 的确认并执行主入口；为 frozen L3 增加显式 task create --start；不传 --start 时 task create 继续只创建 draft，并保留分步 create/start。

## 为什么
复用既有冻结、创建和启动状态机即可把常规路径缩短为一条命令，同时维持脚本兼容性和可排障的显式生命周期。
