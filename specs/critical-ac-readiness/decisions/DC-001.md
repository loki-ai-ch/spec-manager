# DC-001 — 采用只读 Critical AC readiness projection 作为治理准备度事实源；先交付 core/API，扫描 active L3 并分类 missing、empty、unknown、ready，输出 ratio、summary、recommendations 和 governed upgrade 判断。

> 关联 spec: **critical-ac-readiness-L1**  |  状态: **active**

## 决定
采用只读 Critical AC readiness projection 作为治理准备度事实源；先交付 core/API，扫描 active L3 并分类 missing、empty、unknown、ready，输出 ratio、summary、recommendations 和 governed upgrade 判断。

## 为什么
governed default 依赖真实关键 AC。项目当前缺口较多，自动补写会伪造验收语义；只读 projection 能完整暴露缺口并为后续 CLI/修复建议提供稳定契约，同时不修改历史 spec 或 Task。
