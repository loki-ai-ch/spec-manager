# DC-001 — assist guide 在 completed task 且用户表达交付/总结/最终回复意图时推荐 assist delivery；证据、AC 覆盖、验收意图仍推荐 assist acceptance；未完成任务继续 task-next。

> 关联 spec: **delivery-guide-routing-L1**  |  状态: **active**

## 决定
assist guide 在 completed task 且用户表达交付/总结/最终回复意图时推荐 assist delivery；证据、AC 覆盖、验收意图仍推荐 assist acceptance；未完成任务继续 task-next。

## 为什么
交付摘要已成为最终回复前的用户出口，弱 Agent 不应依赖记忆新命令；同时必须保留验收证据审查和未完成任务导航的边界。
