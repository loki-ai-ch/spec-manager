# DC-001 — 采用 assist guide 作为能力补偿层的引导式下一步推荐入口

> 关联 spec: **guided-assist-workflow-L1**  |  状态: **active**

## 决定
采用 assist guide 作为能力补偿层的引导式下一步推荐入口

## 为什么
现有 assist 子命令已完成，但用户和较弱 Agent 仍需记忆何时调用。assist guide 以只读、可解释、确定性规则串联 brief/critique/next/drift/acceptance，降低使用门槛且不改变状态机。
