# DC-001 — task complete 成功输出增加 assist delivery nextCommand 提示；text 输出追加 Next 块，JSON 增加 nextCommand 字段；core completion 门禁、状态机、cascade 和 audit 不变。

> 关联 spec: **task-complete-delivery-hint-L1**  |  状态: **active**

## 决定
task complete 成功输出增加 assist delivery nextCommand 提示；text 输出追加 Next 块，JSON 增加 nextCommand 字段；core completion 门禁、状态机、cascade 和 audit 不变。

## 为什么
Task 完成后最终交付摘要是弱 Agent 容易遗漏的最后一步，把下一步命令放进成功输出能减少记忆负担，同时保持完成逻辑稳定。
