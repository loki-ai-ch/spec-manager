# DC-001 — Separate topic selection from recommendation, enforce path containment, normalize multilingual conflicts, and validate knowledge metrics via resolver-backed projections.

> 关联 spec: **spec-knowledge-operational-closure-hardening-L1**  |  状态: **active**

## 决定
Separate topic selection from recommendation, enforce path containment, normalize multilingual conflicts, and validate knowledge metrics via resolver-backed projections.

## 为什么
These decisions prevent inferred-topic drift, root escape path trust errors, Chinese conflict misses, and stale knowledge annotations from silently shaping future workflow guidance.
